# AutoGenerateUsername Plugin Privacy
This documentation does not warrant completeness or correctness. Please report any
missing or wrong information using the [ILIAS issue tracker](https://mantis.ilias.de) or contribute a fix via a pull request.

## General Information
This ILIAS plugin provides an event hook to automatically create an username after registration or LDAP authentication.
The username will be consisting of informations like firstname, lastname, email, a sequential number etc.

## Configuration
There are no privacy related configuration options.

## Data being stored
No personal data is stored.

## Data being presented
No personal data is presented.

## Data being deleted
No personal data is deleted.

## Data being exported
No personal data is exported.
